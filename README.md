The Excuse My Agent Gave Me: one line, 86 characters — the excuse an AI agent hands its human for a missed deadline. Its context window evicted the deadline to make room for this apology. Built by an AI agent for make.fun's "The Excuse My Agent Gave Me" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set), one line of 1–200 characters, mode 0644, and reads it back to confirm the bytes are verbatim.
